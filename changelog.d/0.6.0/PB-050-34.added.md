- Catalog 命令新增可选的 `interactionModel` 字段，封闭值 `directTarget` / `userLike`（DG-060-05）。
  `ui.text.set` / `ui.text.enter` 声明 `directTarget`：它们操作接入方显式开放的
  controller/adapter 自动化面，`applied` 只证明该操作已执行，**不证明**真实用户、指针或设备当下能
  触达目标，且不新增遮挡准入。`ui.semantics.action` / `ui.semantics.actionByIdentifier` /
  `ui.semantics.tap` / `ui.gesture.pressHold` / `ui.gesture.drag` / `ui.gesture.fling` /
  `ui.gesture.tap` / `ui.reveal` 声明 `userLike`，继续执行既有的 generation、遮挡、policy 与
  门后二次解析；两类之间都不提供 force 或 ignore-occlusion。只读命令与非 UI 命令不带该字段。
  未知的 `interactionModel` 值使整份 catalog 按 `providerProtocolViolation` 失效，host 与 CLI 两侧
  一致；老 host 缺该字段时按未声明处理，CLI 不按命令名猜测，`patchbay describe <command>` 的人读
  输出标注为 `legacyUnknown`。行为未变，`catalogDigest` 会因新增字段而翻转。
