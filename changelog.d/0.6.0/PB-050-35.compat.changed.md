- 目标 identifier 零匹配或已挂载但被遮挡时，`ui.reveal` 不再返回 `uiRevealNoScrollableContainer`，而是
  返回新增的 `uiRevealTargetNotFound` / `uiRevealTargetObscured`。老 CLI 未经改动仍把它们归入既有
  rejected 分类，退出码不变；新 CLI 面对 0.6.0 之前的 App 仍会收到合并后的
  `uiRevealNoScrollableContainer`，那是 legacy ambiguous——CLI 不会替老 host 改写码，也不会自行猜测遮挡。
  按码分支的脚本请把这两个新码也纳入判断。
