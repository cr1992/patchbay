- **Breaking:** `package:patchbay/patchbay.dart` 与 `package:patchbay_flutter/patchbay_flutter.dart` 收窄为按角色
  分层的封闭清单：默认 core 入口只保留 77 个 consumer 符号（命令注册与 descriptor、参数与响应 schema、gate、
  catalog/snapshot provider、job、artifact/blob/log、navigation 与 UI 声明），默认 Flutter 入口不再整库
  re-export core，只在该清单上追加 `PatchbayKey`、`PatchbayRoot`、`PatchbayRootController` 与
  `PatchbayUiRegistry`。新增三个显式入口承接其余符号：`package:patchbay/patchbay_host.dart`（默认清单的严格
  超集，再加 `PatchbayServiceHost`、audit、invocation/cancellation 与 validation lifecycle）、
  `package:patchbay/patchbay_protocol.dart`（生成 wire 类型、catalog capability/digest、CLI syntax、permission
  companion、client 请求与 canonical descriptor）、
  `package:patchbay_flutter/patchbay_flutter_host.dart`（core host 清单加全部 Flutter service host、bridge 与
  policy）。wire、错误码、稳定 JSON、资源上限与运行时行为都没有变化，本项只改 Dart 源码可见性。
  迁移：旧 import 会编译失败，按报错点名的符号在[使用指南的迁移表](docs/guide.md#05x--060-source-迁移表)里
  查对应入口；host 与 protocol 不互相 re-export，同一文件跨角色时写两个显式 import。不提供 `legacy.dart`，
  也不保留兼容的整库 re-export。`patchbay_cli`、`patchbay_client` 与 `patchbay_transport` 的公共符号集合不变。
