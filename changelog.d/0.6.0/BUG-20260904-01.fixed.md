- **Breaking:** `command_codegen` 合约的 `descriptorImport` 改为只接受 host 入口
  `package:patchbay/patchbay_host.dart` 或 `package:patchbay_flutter/patchbay_flutter_host.dart`；
  生成的命令代码构造 `PatchbayRejection`、调用方构造 `PatchbayInvocation`，两者在 0.6.0 的
  API 分层里都是 host-only，此前 0.5.x 的两个 consumer 面取值会产出编不过、且因带
  DO-NOT-MODIFY 标记而无法手改的文件。迁移：把合约里的 `descriptorImport` 换成同包的
  `_host` 入口再重新生成——旧值现在会被逐值拒绝并在错误信息里点名唯一替代值。
