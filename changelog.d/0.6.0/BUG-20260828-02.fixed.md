- 权限 adapter（Android / iOS）的 exercise 与 physical 分流、以及 CLI 无 trace 路径的入口，
  此前在 try 块里不 `await` 直接 `return` 一个 async callee：callee 抛出的失败因此绕过外层
  catch 的类型化翻译，以裸异常逃给调用方，而不是既定的类型化拒绝（如 `systemUiUnexpected`、
  `permissionDecisionUnsupported`）或 usage 信封。现在四处均改为 `return await`，失败一律落回
  类型化答复；可达成功路径的行为与 JSON 不变。
