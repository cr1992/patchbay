  artifact（`renderedMember` / `payloadBlob` / `responseBlob`）；CLI、REPL 与 one-shot 用同一个解释器按
  artifact → brief → `localView` / `localRoute` 的固定顺序执行，`--view full` 仍是恒等投影。新协议命令
  因此只在 descriptor 登记一次，不再同时扩 CLI 投影表、artifact disposition 与命令名特例。声明是松读
  catalog sibling，`schemaVersion` 仍为 `1`，catalog digest 按既有「commands 全对象」口径自然覆盖它；
  老 reader 忽略该键。受限路径的首段不得以 `local` 开头——`localView` / `localRoute` / `localArtifact` /
  `localKeepAwake` 由 CLI 在投影之后追加，声明只能选择 App 返回的成员。声明非法（未知键、错类型、
  超长、重复规则、非法组合、保留命名空间）时整份 catalog 失效而不是丢掉坏字段继续调用：host 侧按
  `providerProtocolViolation` / `invalidOutputProjection` 拒绝服务该 catalog，CLI 侧按
  `catalogOutputProjectionInvalid` 拒绝使用它，`patchbay catalog` 与 `patchbay doctor` 这两条直读路径
  同样覆盖，其中 doctor 仍读出文档并指名违规而不是只报读取失败。
