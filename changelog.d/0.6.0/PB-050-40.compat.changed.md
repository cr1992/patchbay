- `--view brief` 与本地 artifact 的规则来源改为 descriptor 声明，行为对既有命令不变：老 host 缺声明时
  沿用冻结的 0.5.0 fallback（`ui.semantics.tree`、`logs.query`、`logs.export`、`ui.capture`），相同
  descriptor-less 输入的 brief 输出、`localView.projection` 与 `localView.omitted` 字面量及其顺序逐字节
  不变；`catalog` 与三棵 Flutter diagnostic tree 的声明留在 CLI 本地，不进 host catalog。无声明的
  consumer external command 保持 legacy passthrough，只执行全局 `$.notice` 规则且 `localView.projection`
  为 `null`，CLI 不再按响应形状猜命令族。新 host 的 catalog 行只多出 `outputProjection` 一个键，老 CLI
  读到它会原样透传到 `--view full` 输出里。
