# PB-050-24 接入漏斗只读闭环验收

> 状态：已验证
>
> 日期：2026-08-25

## 结论

从干净 `dev/0.5.0` 检出出发，严格按 `skills/use-patchbay/INSTALL.md`（dev 模式）与
`SKILL.md` 的 starter 命令块逐条执行，iOS 模拟器上完成
`INSTALL -> SKILL -> identity/catalog/snapshot` 只读闭环：六条命令全部退出码 0，
未读取 starter 块之外的任何文档，未使用任何写命令。

## 环境

- 检出：`dev/0.5.0`（本报告随验收 MR 提交，基线见该 MR 的 merge base）
- 设备：iPhone 17 Pro 模拟器（iOS 26.5），App debug 构建
- CLI：按 `tool/example_session.sh` 内容指纹构建的 AOT 产物（INSTALL.md dev 模式要求）
- 执行体：maintainer 侧 Agent，输入面限定为 INSTALL.md 与 SKILL.md 两份文档——是「无先验
  consumer」的近似而非严格实现，判定权留给评审

## 结果

| 步骤 | 命令 | 退出码 | 关键观察 |
|---|---|---:|---|
| 1 | `--json doctor` | 0 | session/连接/catalog/lifecycle 一次通过 |
| 2 | `--json identity` | 0 | `applicationId=dev.patchbay.example`，`serverVersion=0.4.1`（开发期稳定锚点，符合版本计划口径） |
| 3 | `--json catalog` | 0 | 输出约 1.26k 行——印证 PB-050-21 brief 视图的动机 |
| 4 | `--json describe example.counter.increment` | 0 | live descriptor 含 retry 资格 |
| 5 | `--json snapshot` | 0 | 全量 413 字节 |
| 6 | `--json snapshot --path counter` | 0 | 字段选择路径可用 |

## 复现

```sh
source tool/example_session.sh
example_session_start <ios-simulator-udid>
example_session_cli --json doctor    # 以下按 SKILL.md starter 块逐条
example_session_cli --json identity
example_session_cli --json catalog
example_session_cli --json describe example.counter.increment
example_session_cli --json snapshot
example_session_cli --json snapshot --path counter
example_session_stop
```
