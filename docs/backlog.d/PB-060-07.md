## 动机

GitLab 与 GitHub CI 已有 API surface、错误码、结构和 pana 等 ratchet，却没有逐包覆盖信息；1.0 承诺前无法直接回答稳定 JSON、错误码和兼容分支哪些仍没有测试证据

## 备注

两套 CI 已复用 `repo_tasks.dart coverage` 为四个发布包与 workspace 外 example 生成五份 branch LCOV，并保留三个 Dart 包的 raw JSON；报告路径统一规范化为仓根相对路径并作为 30 天 artifact 上传，GitLab/GitHub 均为失败可见但不阻断的 informational lane；本版不设百分比硬门，生成代码、平台不可达分支与后续分包下限留待稳定基线后的独立裁决
