## 动机

同一 UI 任务分散在注册 target、Semantics action、pointer gesture 与 reveal 四条入口，使用者必须先理解内部身份域与执行通道才能选命令，0.5.0 的 help 只降低解释成本，没有降低选择成本

## 备注

[任务导向 UI 命令入口](../proposals/0.6.0/task-oriented-ui-entry.md)（已接受）；DG-060-01 已裁决 canonical `ui perform`、`target:/semantics:/node:` selector 与仅 tap 必填的 `--via semantics` 或 `--via pointer`，旧写入口 0.6.0 保留告警、1.0 删除
