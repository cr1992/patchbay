## 备注

[Gate 声明与执行真源](../proposals/0.6.0/gate-execution-boundary.md)（已接受）与 [DG-060-04](../backlog.d/DG-060-04.md) 已接受富化：core 仅从 schema 已校验的 accepted reveal payload 投影 `steps` 与最多 200 个 `containerNodeIds`，不含 identifier、坐标、文案或 policy 文本。该前提要求 `ui.reveal` descriptor 自身声明 `responseSchema`（本条目一并落地，`schemaMode` 随之变为 `validated`）；schema 无法表达的语义不变式（`steps == 0` 时容器列表为空、nodeId 去重）留在 host 投影器按 defect 通道处理
