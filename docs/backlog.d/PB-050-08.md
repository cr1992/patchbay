## 动机

正常 `--json repl` 已按行输出 compact JSON，但 transport / protocol / session failure 冒到 one-shot `_fail` 后会变成多行 pretty JSON；按行消费方无法把它识别为终止事实，FIFO 写端随后可能在 reader 已退出时挂死

## 备注

复用既有 error envelope 与退出码，只修复已承诺的 JSONL 一致性；不在本条加入 reconnect
