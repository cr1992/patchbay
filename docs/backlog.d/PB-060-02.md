## 动机

`patchbay` 默认 library 当前公开 247 个符号，`patchbay_flutter` 又整体 re-export core；API golden 能阻止漂移却不能替默认 consumer 区分高阶 host/wire 类型，若 0.6.0 是 1.0 候选就必须在长期承诺前收口

## 备注

[Core 公共 Dart API 分层](../proposals/0.6.0/core-public-api-layers.md)（已接受）；DG-060-02 已裁决默认 consumer、显式 core/Flutter host 与 protocol 入口，当前 247 个 core 符号按 77 consumer、41 host-only、129 protocol 精确分组，Flutter 默认只保留四个 widget 侧自有符号
