## 动机

接入方首次使用 `ui perform set-text` 就踩到 `ui.text.set` 不跑 `inputFormatters`、不调 `onChanged` 的设计差异，表单状态不动、提交按钮恒禁用，而 canonical 家族的名字与 summary 都不表达这层差别；同一会话里 `target:` 与 `semantics:`/`node:` 两种 generation 同名不同源，分别撞上 `uiGenerationStale` 与 `uiSemanticsGenerationStale`

## 备注

[任务导向 UI 命令入口](../proposals/0.6.0/task-oriented-ui-entry.md)（已接受，2026-09-03 裁决修订）；canonical 只保留 `enter-text`，`ui text set` 迁移目标改指 `enter-text` 且 deprecated 窗口不变，wire 与 host 零变化；help 标明两类 selector 的 generation 来源，stale 拒绝不自动重发
