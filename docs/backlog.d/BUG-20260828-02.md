id: BUG-20260828-02
title: 权限 adapter 与 CLI 入口在 try 块裸 return async callee，类型化失败绕过 catch 逃逸
status: 已验证
---

## 动机

pub.dev 对 patchbay_cli 0.5.0 的站点分析（Dart 3.13.2 analyzer 的新 lint `unawaited_return_in_try_block`）报出 4 处「try 块内不 await 直接 return Future」：`android_permission_adapter.dart` 的 exercise 分流、`ios_permission_adapter.dart` 的 physical 分流与 exercise 分流、`cli.dart` 无 trace 路径的 `runZoned`。这不只是丢 20 个 pub points（站点 140/160，本地 3.12.2 工具链原理上看不见该 lint）：四处的 callee 都是 async 函数，其抛出的 `_AdapterFailure` / `_IosFailure` / `FormatException` 本应被外层 catch 翻译成类型化拒绝（rejected driver response / usage envelope），裸 return 让 Future 的 rejection 绕过 catch、以裸异常逃给调用方——正是「拒绝也是类型化答复」契约要防的缺陷类别；cli.dart 的带 trace 姊妹路径本来就 await，只有无 trace 路径漏了。修复：四处改 `return await`。回归测试先红后绿（Android instrument 无 marker → `systemUiUnexpected` 类型化拒绝；iOS exercise 缺 decision → `permissionDecisionUnsupported` 类型化拒绝）。**已跑证据**：`packages/patchbay_cli` 全量 734 用例（732 + 新增 2）green、`dart analyze --fatal-infos` 零告警、影子环境（真源最新 stable Dart 3.13.2，即 pub.dev 当前分析器）`dart analyze` 零告警。**发布状态：修复已合入 hotfix/0.5.1 分支，仓主裁决暂不发布**；发布时随 0.5.1 走完整 hotfix 流程。伴生流程改进：发版清单新增「影子环境预检」（用真源最新 stable SDK 复跑 analyze/Pana，防本机工具链与 pub.dev 分析器的 lint 集漂移——本机与 CN 镜像当时都停在 3.12.2，真源已是 3.13.2）
