## 动机

PB-050-25 的根因是 domain descriptor 的 gates 曾是 catalog 装饰、dispatch 未强制执行,暴露"声明真源与执行真源分离"的结构风险;现状已核实:PB-050-25 当前 `status: 实现中`,`packages/patchbay/lib/src/host/host_invoker.dart` 已在 `_dispatchExternal`/`_domainGateRejection`(437-469,504-524 行)补上 `_domainGates` 受理层强制,对应裁决为 DG-050-11 与已接受的 domain gate 强制执行 Proposal;0.5.0 已补 host 受理层强制,但边界未成体系。方向:core host 负责 descriptor/sideEffect/声明门/审计;Flutter bridge 只负责 UI 特有的目标解析/generation/遮挡/派发;consumer adapter 不得自行决定哪些 descriptor 字段只是展示——否则新增第三种 plane 可能再漏一次
